01 : PROBLEM

The problem in one picture

The structural challenge facing urban electric vehicle drivers and highway mobility

[ Node 01 ]

Apartment

No dedicated charger. Lack of dedicated electrical capacity in multi-tenant garages.

Constraint: Residents cannot install private charging stations.
[ Node 02 ]

EV OWNER

Needs routine charging. Demands predictable schedule without time loss.

Friction: Forced to divert productive hours to seek charging options.
[ Node 03 ]

Public charger

Travel + wait + availability uncertainty. Out-of-service hardware and queues.

Outcome: Inconsistent charging experience and schedule disruption.

The second problem: long-distance EV travel can have charging gaps, while many private chargers sit unused for hours.

Opportunity: connect convenience with underutilized charging capacity.

Critical Design Decision

A highway traveller should not need a company driver at every residential charger. The system therefore supports secure self-service.

Host Privacy: Homeowners require zero physical interaction with visitors. Access is managed through automated IoT gating.
Scalable Throughput: Removes staffing constraints along highway corridors, enabling continuous 24/7 self-service charging.
05 : TRUST

Security: a charger is not an open door

3-tier virtual perimeter safety framework

GREEN : SAFE ZONE
Authorized charging area

Designated vehicle bay and EVSE dock. Normal charging activity permitted for authenticated user.

YELLOW : WARNING ZONE
Warning + continued monitoring

Perimeter buffer zone (3m boundary). Audio courtesy notice and continued visual motion tracking.

RED : RESTRICTED ZONE
Alarm + notification + event log

Private residential entryway. Triggers immediate alert, EVSE power cutoff, and immutable incident log.

CCTV + virtual perimeter monitoring keeps the charging interaction controlled. The zones are a conceptual safety framework designed to reduce unwanted movement and false alarms.

OWNER MODE
Owner authenticates -> uses charger -> session ends -> lock

Host retains priority access for personal vehicles with direct NFC/phone tap. No platform billing or reservations required.

TRAVELLER MODE
Booking creates temporary authorization -> secure session -> lock

Time-bound authorization window issued upon confirmed booking. Re-locks automatically upon disconnect or session completion.

Safety: the external module is a security/monitoring controller. High-current charging should remain under a properly rated EVSE and supported control mechanisms.
07 : VERIFICATION

Every session leaves evidence

Objective audit trail before, during, and after charging

BEFORE

Condition photos logged: Vehicle, port, connector, cable, charger, and area.

CHARGING

Continuous recording: Real-time telemetry + CCTV stream + immutable session log.

AFTER

Repeat photos taken at matching angles + computer vision condition comparison.

AI / computer vision: flags possible visible differences.

Human/technical verification: determines what actually happened and supports liability decisions.
